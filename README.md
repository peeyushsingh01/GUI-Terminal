# Interactive Number Analyzer

A GUI-based Python program that collects integers from the user and performs basic data analysis on them.

## Features

- Interactive GUI using PySide6
- Keyboard-based number input
- Add multiple integers
- Backspace support for editing input
- Animated text using QTimer
- Calculate:
  - Maximum value
  - Minimum value
  - Sum
  - Average
  - Number of even values
  - Number of odd values
- Simple interactive command system using keyboard shortcuts

## Controls

| Key | Action |
|---|---|
| Y | Start |
| N | Exit |
| R | Restart |
| Enter | Save number |
| Backspace | Delete last digit |
| F | Finish and analyze |
| 0-9 | Enter numbers |
